Vad är CSS?

CSS används för att bestämma hur en webbsida ska se ut. Med CSS kan du ändra färger, textens storlek och hur texten presenteras.

Saker att prova

  • Ändra textens färg
  • Ändra sidans bakgrund
  • Ändra textens storlek
  • Välja rätt tysnitt
  • Ändra textens tjocklek
  • Använd text-align för att flytta texten

"Bra CSS handlar inte bara om hur sidan ser ut – utan om hur den känns att läsa."
